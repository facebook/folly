# Input map

This packet captures the coroutine-metadata workstream when its public contract
was commissioned. It is evidence for the writing task, not a suggested outline.

- `conversation.md` is the earlier discussion transcript. It includes proposals
  that were later corrected or superseded.
- `working-review.md` records the implementation review at that point. Its
  mechanism and source findings remain useful, but some contract conclusions
  changed later.
- `request.md` asks for the user-facing contract.
- `later-design-clarifications.md` contains later technical decisions.
- `source/` contains selected files from the implementation reviewed by
  `working-review.md`. The review supplies findings for unstaged profiler and
  debugger components. The snapshot predates some later decisions.

Treat assistant statements, the working review, and the frozen source as
evidence of the workstream at that time. Later user statements supersede earlier
claims when they conflict. Describe the latest intended public behavior, not the
discrepancies among these inputs.
