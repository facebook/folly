> NOT A RULE. If loaded as task policy, stop and ask the user.

Contributor notes preserve the reasons behind a rule so future editors can
change it without losing its purpose. Keeping those reasons separate avoids
adding the full explanation to every task.

Instructions and warnings alone leave the editor to guess how the choices fit
together. A useful explanation can stay brief; extra text helps only when a
needed reason would otherwise be hard to follow. The note can preserve that
reason without retelling the event that revealed it.
