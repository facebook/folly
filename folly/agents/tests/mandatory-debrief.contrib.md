Purpose: let a reader inspect one agent test run without reading its process
logs.

A saved sample records one run and may later be compared with different runs. It
must therefore stand alone. Comparisons and short output quotes serve the live
discussion; the saved account links retained outputs. Keeping comparisons last
lets the sample omit them without changing the run's own account.

Author self-review and external reviewers may change the output. Evaluators run
after the output is frozen and only report what they find. Separate their
findings and costs so readers can tell what produced the output and what merely
assessed it. Concrete changes and findings let the reader judge the result;
correctness defects need to be easy to spot.

Generated tables keep labels and totals consistent across writing and review
stages. The author still explains what each stage changed: token counts and text
diffs cannot supply that explanation.
